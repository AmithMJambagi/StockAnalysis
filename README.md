# Stock Market Analysis

A web-based application for analyzing stock market data, featuring interactive charts and real-time stock information.

## Features

- Interactive line chart displaying stock prices over various time periods (1 Month, 3 Months, 1 Year, 5 Years)
- Stock selection from a predefined list (AAPL, MSFT, GOOGL, AMZN, PYPL, TSLA, JPM, NVDA, NFLX, DIS)
- Hover effects on the chart with vertical lines and tooltips
- Highlighted maximum and minimum price points
- Display of current stock price and profit percentage
- Company profile summaries

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Chart.js for data visualization
- External APIs for stock data

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/your-username/stock-trading.git
   ```

2. Navigate to the project directory:
   ```
   cd stock-trading
   ```

3. Open `index.html` in your web browser.

## Usage

- Select a stock from the list on the right to view its chart.
- Use the time period buttons below the chart to change the data range.
- Hover over the chart to see detailed price information and vertical hover lines.
- View company details in the section below the chart.

## API Sources

This application uses the following external APIs:
- Stock data: https://stock-market-api-k9vl.onrender.com/api/stocksdata
- Stock stats: https://stock-market-api-k9vl.onrender.com/api/stocksstatsdata
- Company profiles: https://stock-market-api-k9vl.onrender.com/api/profiledata
